## 网站结构

```

├── index.html          # 中文版首页
```

## 技术规格

- **纯静态站点**：无后端依赖，无需服务器端语言
- **响应式设计**：支持桌面、平板、手机三端适配
- **现代 CSS**：CSS Variables、Grid、Flexbox、Backdrop Filter
- **轻量 JS**：仅用于滚动动画、移动端菜单、平滑滚动
- **Google Fonts**：Inter + Noto Sans SC（自动加载）

## 部署方式

### 方式一：本地预览
直接双击打开 `index.html` 或 `en.html`

### 方式二：静态托管
上传至以下任一平台：
- **GitHub Pages**：推送到 gh-pages 分支
- **Vercel**：导入项目自动部署
- **Netlify**：拖拽上传或 Git 集成
- **阿里云 OSS**：配置静态网站托管
- **腾讯云 COS**：开启静态页面功能

### 方式三：自有服务器
将文件放置于 Web 服务器根目录，配置域名 DNS 解析即可。
